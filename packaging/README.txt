========================================================================
 harness-go —— 单二进制 AI Agent 服务端
========================================================================

本目录是一个完整的可运行分发包，无需安装 Go / Node.js 运行时。

------------------------------------------------------------------------
 一、快速开始
------------------------------------------------------------------------

Windows：
    双击 start.cmd
    （或在本目录打开命令行执行：start.cmd）

Linux / macOS：
    chmod +x ./harness-go ./start.sh
    ./start.sh

启动成功后浏览器打开 http://127.0.0.1:8080

------------------------------------------------------------------------
 二、首次登录
------------------------------------------------------------------------

首次启动会自动创建管理员账号，并生成随机口令写入：

    data/initial_password

文件内容两行：第一行是用户名，第二行是口令。
用它登录即可（登录后请立刻在「设置 → 账户」里修改口令）。

该文件只生成一次；删除后不会重新生成（已有账号不会再被覆盖）。

也支持免登链接直接进入工作台（默认开启，仅 local 形态）：

    http://127.0.0.1:8080/?user_name=admin&pwd=<口令>

服务端会在校验后 302 跳转到不含凭据的干净地址，口令不会留在
浏览器历史与访问日志中。

------------------------------------------------------------------------
 三、常用启动参数
------------------------------------------------------------------------

    -addr 127.0.0.1:8080     监听地址（默认只绑本机回环）
    -addr 0.0.0.0:8080       让同网段的手机/平板也能访问（注意安全）
    -data  ./data            数据目录
    -config ./my.yaml        使用自定义配置文件
    -mode local              部署形态 local | server | cloud
    -log-level debug         日志级别 debug | info | warn | error

参数会叠加在启动脚本默认值之上，例如 Windows：

    start.cmd -addr 0.0.0.0:8080 -log-level debug

------------------------------------------------------------------------
 四、配置文件
------------------------------------------------------------------------

本目录内附 config.example.yaml，列出全部配置项与默认值（带中文说明）。
需要自定义时：

    Windows:   copy config.example.yaml data\config.yaml
    Linux/mac: cp config.example.yaml data/config.yaml

然后编辑即可生效（数据目录下的 config.yaml 会被自动加载）。

也可用环境变量覆盖，前缀 HARNESS_，例如：
    HARNESS_SERVER_ADDR=0.0.0.0:8080
    HARNESS_USER=admin  HARNESS_PWD=<自定义口令>   （仅首启建号时生效）

优先级：命令行参数 > 环境变量 > config.yaml > 内置默认值。

⚠ 配置不做静默兜底：非法值会在启动时直接报错退出，而不是悄悄用默认值。

------------------------------------------------------------------------
 五、数据与备份
------------------------------------------------------------------------

所有数据都在 data/ 目录内：

    data/main.db                      跨会话共享的主库（会话列表/账号/配置）
    data/sessions/<sid>/session.db    每个会话独立的库（消息/Run/工具事件）
    data/sessions/<sid>/blobs/        会话级大对象（附件、产物、大工具输出）
    data/snapshots/blobs/             文件快照（跨会话去重）
    data/app.log                      运行日志
    data/initial_password             首启口令（仅首次生成）

备份：停止服务后直接复制整个 data/ 目录即可。
迁移到另一台机器：复制本目录 + data/ 目录，再按平台启动。

------------------------------------------------------------------------
 六、访问局域网（手机 / 平板）
------------------------------------------------------------------------

    Windows:   start.cmd -addr 0.0.0.0:8080
    Linux/mac: ./start.sh -addr 0.0.0.0:8080

然后用本机局域网 IP 访问（如 http://192.168.1.10:8080）。
若打不开，通常是防火墙拦截了该端口，需放行。

⚠ 暴露到局域网后，请务必修改初始口令。该形态属 server 形态范畴，
  建议改用 -mode server 并把 config.yaml 的 auth 段切到 SSO signed。

------------------------------------------------------------------------
 七、停止服务
------------------------------------------------------------------------

在运行窗口按 Ctrl+C。服务会优雅关闭（最长 30 秒）：先停止接收新请求，
取消所有在途 Run，落库后关闭数据库。

注意：不要直接用任务管理器强杀进程，否则未落库的流式内容会丢失，
下次启动时这些 Run 会被标记为 interrupted。

------------------------------------------------------------------------
 八、常见问题
------------------------------------------------------------------------

Q: 打开页面显示「前端未构建 / 提示页」
A: 该分发包内前端产物已内嵌，正常不会出现。如出现请确认完整解压，
   不要只从压缩包里拖出 exe 单文件运行。

Q: 页面能开但发消息报错 / 一直回显 [fake]
A: 说明尚未配置模型厂商。进入「设置 → 模型设置」添加厂商与模型
   （Base URL + API Key），或在 data/config.yaml 内配置。

Q: 端口 8080 被占用
A: 换端口启动：start.cmd -addr 127.0.0.1:9000

Q: 忘记口令
A: 停服后删除 data/main.db 会清空所有数据（会话与账号全部丢失）。
   若不希望丢数据，请另用 -data 指定新目录起一个实例，登录后
   通过 API 重置原库账号，或联系维护者。

Q: 想查看更详细的日志
A: start.cmd -log-level debug，日志同时输出到控制台与 data/app.log
   （也可通过 GET /api/v1/logs 读取尾部）。

------------------------------------------------------------------------
 九、健康检查与版本
------------------------------------------------------------------------

    GET /healthz          返回 {"status":"ok","version":...,"protocol_version":...}
    GET /api/v1/auth/me   需鉴权，可用于确认登录态

/healthz 免鉴权，适合做进程探活与开机自启的等待条件。
