## 2. 本轮解决的环境阻塞（全部已关闭）

| # | 阻塞 | 根因 | 处置 |
| --- | --- | --- | --- |
| E1 | `pub get` 报 `requires symlink support` | Windows 开发者模式未开启 | 提权写 `HKLM\...\AppModelUnlock\AllowDevelopmentWithoutDevLicense=1`，重登生效 |
| E2 | `flutter analyze` 报 4 个 `Color.withValues` 未定义 | SDK 退化到 3.24.5（该 API 需 ≥3.27） | SDK 恢复到 3.47.9 后消失 |
| E3 | Windows 构建 `MSB3073: NUGET-NOTFOUND` | nuget 装在用户级 PATH（MSBuild 不继承） | 改装 `%USERPROFILE%\.nuget-cli` + **系统级** PATH；并清理 `CMakeCache.txt` 里固化的旧 `NUGET:FILEPATH` |
| E4 | Windows 构建 `error C2338: STL1011 /await` | VS2026 默认 MSVC 14.51 把旧协程升为硬错误 | 补装 v143 工具集 + **ATL**，并在 `windows/CMakeLists.txt` 注入 `CMAKE_GENERATOR_TOOLSET=v143` |
| E5 | Windows 构建 `C1083: atlstr.h 找不到` | 首次装 v143 时漏装 ATL 组件 | 补装 `Microsoft.VisualStudio.Component.VC.14.39.17.9.ATL` |
| E6 | Android 构建「看似卡死 15 分钟」 | Gradle 下载缺失的 3 个 ABI 引擎 jar（各 100MB+） | 改 `--target-platform android-arm64` 单架构，120.8s 出包 |
| E7 | Android `checkDebugAarMetadata` 失败 | `compileSdk=35` 过低 + 缺 desugaring | 升 36；启用 `coreLibraryDesugaringEnabled` + `desugar_jdk_libs:2.1.4` |
| E8 | Gradle 下载恒为 0 字节 | Java 不读 `HTTP_PROXY` 环境变量 | 显式写 `-Dhttp.proxyHost/Port` 到 `org.gradle.jvmargs` |

> 🔴 **E1/E4/E5 过程中曾二次致伤**：中断 VS Installer 会使 `state.errors.json` 写入 `skippedPackages`，
> 导致 `vswhere` 报 `isComplete=False`，Flutter 与 CMake **双双拒绝识别该 VS 实例**。已记录纪律：**安装器进程绝不可中断**。
